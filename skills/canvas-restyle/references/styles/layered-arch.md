## 角色与样式
- 层框（原黑色虚线框）：浅灰蓝虚线**线框**（`FR`，4 线 + 4 圆角）；嵌套的公共服务层用点线。左侧层标签做成整层高的标签卡（同运营看板：底色 + 5px 竖条 + 20 粗）。
- 用户旅程 / 价值流：渐变箭头多边形（金 `#fff6dd→#fde9b6` / 绿 `#e9f8ef→#cdeedb`），14.5 粗。
- 触点层：平台条用渐变（数字化研发平台 青绿、PLM 靛蓝），模块白卡 + 左侧同色竖条。
- 应用服务 / AI应用：白底分区 + 左上标题胶囊；AI 分区只画粉色线框，内部粉色容器保留。
- 模块容器：白卡 + 顶部 3px 强调线，标题色随原边框分组（金 `#d97706` / 青 `#0f8f8c` / 绿 `#15803d` / 灰 `#475569`）。
- 条目按状态（与图例一致）：已上线 `#e9f7ee/#8fd3a6`，需升级 `#fff5d9/#efc25a`，需新建 白/`#c3ccd8`，AI相关 `#fdeaea/#f2a5a5`；智能体保留蓝描边 `#5b7fd6` 并加粗。
- 原「26年Q4 / 27年Q3」80% 遮罩会盖住条目：改为**被覆盖条目靛蓝虚线描边** + 容器标题右侧季度胶囊（标题改左对齐）。
- 同一容器内条目 ≤5px 的行列偏差对齐到中位数。

## 检查器经验
- `--check` 的 node-overlap：内层填充形状面积 ≥ 外层 50% 即报警（嵌套也算）。大层框、大分区要么画成线框，要么保证内层 <50%。
- 文字比对需包含 section 标题（`section.title`）。
