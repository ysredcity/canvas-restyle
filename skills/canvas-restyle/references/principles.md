# 通用视觉原则（与工具无关）

所有适配器都遵守这一页；具体怎么落地见 `adapters/<工具>.md`。来源：此前 15 次飞书画板优化与 PPT 试跑。

## 不变的东西
- 内容、文字（逐字）、元素数量、位置、尺寸、层级、分组不变。只改样式。
- 原文件只读，产出写到新文件 / 新画板。
- 原图「同色同类、异色异类」的区分保留：不同色系不合并，同一原色始终映射为同一新色。
- 原图没有图例时，不臆测颜色含义，不新增图例。

## 颜色
- **收敛**：相近色归入同一色系（7 个：中性 / 青 / 蓝 / 绿 / 琥珀 / 红 / 紫），色系内只用少数几档深浅。
- **整份一致**：样式方案按整份文件（整块画板、整份 PPT）生成，不逐页各自为政。
- **品牌色不动**：文件自带品牌色（如 PPT 母版主色）时，它就是该色系的基准，近似色向它收敛。
- **层次靠深浅、描边、字重**，不靠去色；去色导致层次丢失比多一种颜色更糟。
- **状态色不与板块主色撞色**；强调文字统一为一个强调色，不出现多种红。
- **中性色谨慎**：只在能整体统一时才改中性色（飞书重绘可以；PPT 正文继承母版黑色，只改显式黑色会造成深浅不一，所以不改）。

## 文字
- 文字颜色只有四种来源：墨色、弱化灰、所在色系文字色、深底上的白。
- 字号只用一套层级（标题 / 正文 / 辅助）；放不下时优先缩字或用工具自带的自动缩字，不移动元素。

## 什么时候停下来问
- 要好看只能靠移动 / 缩放元素（违反布局不变）。
- 颜色明显承载语义但无法从原图判断（如灰色可能表示「已完成」）——用 `--map` 前先问。
- 改色后文字对比度不足（方案报告里的对比度警告）且无法在不改文字颜色语义的前提下解决。
