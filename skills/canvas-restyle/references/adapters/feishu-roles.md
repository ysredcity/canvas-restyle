# 飞书画板适配器：redraw.py 角色识别与绘制规则

## 坐标
- section、table 的子节点坐标相对父节点，`lib.abs_box` 逐级累加；group 子节点是绝对坐标，group 本身不画。
- 输出画布 = 全部节点外接框 + 40 边距；中位字号 > 24 时整体等比缩放。

## 角色
| 角色 | 判定 | 绘制 |
|---|---|---|
| container | section；或面积更大且完整包含其他形状的形状 | 圆角多边形（不触发重叠检查）；中性色按嵌套深度交替浅灰/白；彩色保留色系浅底；无填充有描边 → 线框；虚线保留；顶层有底色加阴影；形状自带文字放左上作标题；section 标题放框外左上 |
| step | `step` / `step2` 形状 | 同一行按 x 排序画成 » 箭头链；与下一个起点叠压时把宽度收到下一个起点前（会在交付说明里提） |
| overlay | 半透明（15%–95%）且盖住其他形状 | 不再填色（会盖住条目），改为色系深色虚线框 + 右上角骑线角标（遮罩文字，如「26年Q4」） |
| card | 其余带填充/描边的叶子形状（含表格内胶囊） | 色系浅底 + 同色描边圆角卡；深色原底 → 深底白字；细条（短边 < 12 且无字）画成粗线；与其他卡部分重叠 ≥50% 时改画多边形 |
| text | text_shape | 原位排版；颜色按所在形状色系取文字色 |
| table | table 节点 | 表头深青白字，隔行浅底，网格只画上/左线，合并单元格保留，单元格原色按色系映射 |
| connector | 直线/折线/曲线，含吸附端点 | 按端点重画（曲线按直线），箭头按 `arrow_style`；颜色按原色系，中性用默认连线色 |
| image | 内联 SVG 的 polygon 小图标（如流程三角） | 重画为连线色；若盖住某段文字左上角，向远离文字方向压缩（避免检查器误判溢出）；含 path 的复杂图片跳过并报告 |

另外：无字、与外层卡同色且大部分落在其内的装饰块（原图用来补直角）跳过不画。

## 文字颜色
原文字色接近白 → 白（深底）或墨色；中性色 → 亮度高用弱化灰、否则墨色；彩色 → 对应色系文字色。
富文本里的段内粗体：每段能单行放下时用多个 `<text>` 手动排位保留粗体（不用 tspan）；放不下则按普通文本排版。

## 常见误判与处理
- 浅灰底其实是语义色（如「已完成」）→ `--map "#xxxxxx=neutral/soft"` 或改到某色系。
- 两种相近的蓝被归入同一色系、但原图想区分 → `--map` 把其中一个指到 `purple` 或 `teal`。
- 某个大底板被识别成 card（它没有完整包含子形状，只是被压在下面）→ 写覆盖脚本，把该 id 强制设为 container：
  ```python
  from redraw import Painter; P = Painter(nodes, style, {}); P.role['o1:123'] = 'container'; P.run().save('diagram.svg')
  ```
