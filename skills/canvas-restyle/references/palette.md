# 默认色板（scripts/core/palette.json）

## 色系归类（core/color.py `family_of`）

所有适配器共用这套归类与取值；各适配器只决定「哪种深浅用于哪种元素」。
原色按 HLS 归类：
- 中性 neutral：饱和度 < 0.12，或很浅且饱和度 < 0.25，或很深（亮度 < 0.25）且饱和度 < 0.35（近黑色）；亮度 > 0.97 视为白（white）。
- 彩色按色相：红 <15°/≥345°，琥珀 15–65°，绿 65–160°，青 160–195°，蓝 195–255°，紫 255–345°。
- 深浅：亮度 < 0.62 为 solid（深底白字），否则 soft（浅底深字）。

## 品牌色锚定（core/palette.py `anchor_family`）
PPT 母版里最常用的彩色视为品牌色：该色系 accent = 品牌色本身，soft / solid 由它按比例混白 / 混黑推导，
同色系近似色（如 `#18b4b8` 之于 `#00aaa6`）收敛到品牌色。品牌色本身永远不改。

其他：墨色 `#1f2937`，标题 `#0f172a`，弱化 `#64748b`，容器底 `#f6f9fc`/白交替、描边 `#dbe3ec`，连线 `#8aa0c4`，表格网格 `#e5eaf0`；
圆角 卡片 8 / 容器 12 / 小胶囊 6；阴影 dy2 σ4 `#0f2a3d` 7%。

## 设计取向（来自历次优化）
- 收敛颜色数量：原图七八种近似色归入同一色系，异色异类的区分保留。
- 状态色（已上线/需升级/需新建/AI 相关）色相不能与板块主色撞色；新增色系前先核对此表。
- 不奖励「少色」本身：去色导致层次丢失比多一种颜色更糟。

## 覆盖
`--style style.json` 只需写要改的字段，例如：
```json
{"families": {"teal": {"solid": {"bg": "#0f766e"}}}, "connector": "#94a3b8"}
```
